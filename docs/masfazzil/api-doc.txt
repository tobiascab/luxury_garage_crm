Documentación API Masfazzil - Pasarela de
Pagos (Débitos y Catastro)
Esta documentación detalla los procesos para la autenticación, registro de tarjetas, gestión de
clientes y procesamiento de cobros a través de la API de Masfazzil.




1. Autenticación (OAuth2)
Antes de realizar cualquier operación, se debe obtener un token de acceso válido.


     Endpoint: POST https://auth.masfazzil.com.py/oauth2/token
     Body (x-www-form-urlencoded):

        client_id: {{client_id}}
        client_secret: {{client_secret}}
        grant_type: client_credentials



Response (Success)
{
    "access_token": "eyJ0eXAiOiJKV1QiLCJhbGci...",
    "expires_in": 3600,
    "token_type": "Bearer"
}




2. Registro de Tarjeta (/card/register)
Inicia el proceso de catastro de una tarjeta. Este endpoint genera una URL de redirección donde
el usuario final ingresará sus datos de forma segura.


     Endpoint: POST https://gateway.masfazzil.com.py/{{stage}}/api/v2/card/register
     Headers:

        Authorization: Bearer {{access_token}}
        X-Client-Id: {{client_id}}

{

      "document_number": "007352908340",
      "document_type": "CPF",
      "phone": "0981123433"
    }
}

{
  "success": true,
  "status": "success",

5. Eliminar Tarjeta (/card)
Elimina de forma permanente una tarjeta del registro del cliente.


         Endpoint: DELETE https://gateway.masfazzil.com.py/{{stage}}/api/v2/card
         Query Params:

            card_id: ae51a23e-e8d0-4433-9558-b4685e4e0dd8

         Headers:

            Authorization: Bearer {{access_token}}
            X-Client-Id: {{client_id}}



Response (Success)
{
     "success": true,
     "status": "success",
     "message": "Tarjeta Borrada"
}

7. Asignar operaciones
Crear Operación

Este endpoint permite crear una nueva operación de débito, incluyendo la posibilidad de adjuntar
un archivo.


Endpoint: POST https://gateway.masfazzil.com.py/{stage}/api/v2/debit/operations


Headers:


         Authorization: Bearer {{access_token}}
         X-Client-Id: {{client_id}}


Request Body (Multipart Form Data):


    Campo                       Tipo      Requerido Descripción       Ejemplo
    client_uuid                 string    Requerido ID del cliente    '123e4567-e89b-12d3-
                                                    asociado a la     a456-426614174000'
                                                    operación.
    institution                 string    Requerido Nombre de la      'Banco Nacional'
                                                    institución
                                                    financiera.
    description                 string    Opcional   Descripción de   'Préstamo personal'
                                                     la operación.
    installments                integer   Requerido Número de         12
                                                    cuotas de la
                                                    operación
                                                    (mínimo 1,
                                                  máximo 120).
    start_date               string   Requerido Fecha de inicio   '2024-01-15T00:00:00.000Z'
                                                de la operación
                                                (formato ISO
                                                8601).
    amount_per_installment number Requerido Monto por cuota 150000.5
                                            (mínimo 1).
    first_due_date           string   Requerido Fecha de         '2024-02-15T00:00:00.000Z'
                                                vencimiento de
                                                la primera cuota
                                                (formato ISO
                                                8601).
    code                     string   Requerido Código único de 'OP-2024-001'
                                                la operación.


Ejemplo:

Request Body


{

Notas:
      Al eliminar un cliente, también se eliminarán automáticamente:
          Todos los tokens de pago asociados (ClientPaymentToken)
          Todas las operaciones asociadas (Operation)
          Todos los detalles de operaciones (OperationDetails)

      Esta acción es irreversible. Asegúrate de confirmar antes de ejecutar.
